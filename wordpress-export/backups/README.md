# Former WordPress design backup

`njcglobal-former-wordpress-content-2026-09-13.zip` contains the WordPress WXR export downloaded before the NJC theme preview work continued.

The export preserves the site's posts, pages, comments, custom fields, categories, tags, navigation menus, custom post types, and Pagelayer-related page content stored as post metadata.

Important: this is a content backup, not a complete hosting backup. It does not contain the WordPress core installation, plugins, uploaded media files, the PopularFX theme files, or every database option. The PopularFX theme remains installed and active on the live site. Backuply was also asked to make a full files-and-database backup, but that job stalled and did not produce a verified archive, so it is not being treated as recoverable.
